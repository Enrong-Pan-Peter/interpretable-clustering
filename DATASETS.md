# Datasets — download & setup

## TL;DR
For Phase 0/1 you do **not** need to hand-download anything. The paper's seven UCI sets
are pulled programmatically, and the synthetic sets are generated in code.

```bash
pip install -r requirements.txt      # includes ucimlrepo
python scripts/fetch_uci.py          # downloads + caches all 7 UCI sets to data/uci/
python scripts/demo_fairness.py                 # fairness demo on synthetic
python scripts/demo_fairness.py ionosphere      # same demo on a real UCI set
```

## 1. Synthetic (no download)
Generated by `atomicplus/datasets/synthetic.py` — ships labels + true defining features:
- `two_cluster_subspace(...)` — two Gaussian clusters separated in known dims (fairness / known-answer).
- `subspace_gaussian(...)` — multi-cluster, each with its own dims (re-implements `convex_synth_data.generate2`).
- `nonconvex_projection('2d_data')` — jain/spiral/flame projected into 6-D (uses the repo's `2d_data/*.txt`).

## 2. UCI (programmatic via `ucimlrepo`)
`python scripts/fetch_uci.py` fetches these by id and caches CSVs to `data/uci/`:

| name (in code) | dataset | ucimlrepo id |
|---|---|---|
| `biodegradation` | QSAR biodegradation | 254 |
| `ceramic` | Chemical Composition of Ceramic Samples | 583 |
| `cervical_cancer` | Cervical Cancer (Risk Factors) | 383 |
| `glass` | Glass Identification | 42 |
| `ionosphere` | Ionosphere | 52 |
| `ozone` | Ozone Level Detection (8-hour) | 172 |
| `wholesale` | Wholesale customers | 292 |

The script prints an `ok`/`FAILED` line per dataset with row/feature counts. **Please run
it and paste me the output** — a couple of ids (ceramic 583, cervical 383, ozone 172) I
could not verify from my sandbox (no network to UCI), so if any say `FAILED` I'll correct
the id or switch that one to a manual CSV.

### Manual fallback (only if a fetch fails)
Download the dataset's CSV from https://archive.ics.uci.edu, then place it at:
```
data/uci/<name>.csv            # feature columns (numeric)
data/uci/<name>_target.csv     # optional: single label column named "target"
```
`load_uci(name)` uses the cached CSV automatically. Features are coerced to numeric
(non-numeric columns dropped) and the target is factorised to integer codes.
