# Adversarial novelty audit: sparse native clustering rules

Research snapshot: 14 October 2026. This is a targeted primary-source audit, not an exhaustive novelty clearance. No experiments, installations, or implementation changes were made.

**Verdict:** the proposed package—several small original-feature panels, explicit rules, alternative explanations, abstention, and held-out fidelity guarantees—does not yet identify a new method. Strong prior work covers each component, and several components occur together. A credible thesis hypothesis needs a new search, optimization, or inference result that cannot be recovered by fitting established interpretable models to frozen cluster labels and calibrating them.

The user's preference is 2–3 original features, with larger panels allowed through explicit rules. That is a preference to evaluate, not a universal feasibility assumption. Report distinct budgets for a node, an entire root-to-leaf path, and the union across the tree. Two features in a quadratic expression still means two original features, but expression length and interaction terms are additional complexity.

## Closest threats to the broad claim

| Proposed novelty | Primary-source overlap | What remains different, if demonstrated |
|---|---|---|
| Several interchangeable small feature panels | Bach and Böhm, **Alternative feature selection with user control** (online 2024; journal volume 2025), explicitly searches high-quality, differently composed feature sets, with controls on their number and dissimilarity and sequential/simultaneous formulations. [Paper](https://link.springer.com/article/10.1007/s41060-024-00527-8) | This is supervised feature selection. However, using a frozen cluster assignment as the target immediately reduces the proposed panel problem to this setting. “Unsupervised input” does not invalidate that reduction. Alternative panels preserving a partition differ from alternative clustering that deliberately changes the partition. |
| Multiple concise original-feature descriptions per cluster | Ofek and Somech, **Cluster-Explorer**, PVLDB 2025, returns sets of conjunctions for fixed black-box clustering results. It uses generalized itemset mining and returns a Pareto set for coverage, separation error, and conciseness. Different numerical binnings and categorical predicates enrich the candidate rules. [Author manuscript](https://arxiv.org/html/2412.20446), [published paper](https://www.vldb.org/pvldb/vol18/p1495-somech.pdf) | Its reported criteria are measured on the explanation data. A set of possibly overlapping descriptions is also different from a completely specified assignment policy. Those differences motivate work but do not alone establish novelty. |
| Minimal panels and compact geometric cluster rules | Lawless and Günlük, **Cluster Explanation via Polyhedral Descriptions**, ICML 2023, explains supplied clusters by optimizing polyhedral complexity or feature use; it employs integer programming and column generation. Features used to explain clusters need not be those used to form them. [Paper](https://proceedings.mlr.press/v202/lawless23a.html) | A new minimality claim must specify whether it minimizes distinct features, halfspaces, coefficients, or another cost, and in which rule grammar. Merely using sparse explicit boundaries already has a direct comparator. |
| Several near-optimal interpretable assignment systems | Xin et al., **TreeFARMS**, NeurIPS 2022, enumerates the Rashomon set of sparse decision trees under a threshold on misclassification loss plus a leaf penalty. [Paper](https://papers.nips.cc/paper_files/paper/2022/file/5afaa8b4dd18eb1eed055d2d821b58ae-Paper-Conference.pdf), [author implementation](https://github.com/ubc-systopia/treeFarms) | It uses supervised targets and its objective is not minimum distinct-feature support. Nevertheless, trees fitted to frozen cluster labels are a strong reduction baseline for alternative native rules. A catalogue of similar models is not itself new. |
| Sparse radial/quadratic groups in different feature subspaces | Macha and Akoglu, **x-PACS**, Data Mining and Knowledge Discovery 2018, starts from known anomalies and discovers low-dimensional anomaly groups using axis-aligned hyperellipsoids, mass/purity trade-offs, and compact descriptions. [Author manuscript](https://www.andrew.cmu.edu/user/lakoglu/pubs/18-pkdd-journal-xpacs.pdf), [author publication record](https://www.andrew.cmu.edu/user/lakoglu/pubs.html) | The task is anomaly description, not arbitrary unlabeled clustering. Its coordinate-wise feature descriptions should not be confused with exact ellipsoid membership. Nevertheless, local original-feature subspaces and quadratic geometry are established ingredients. |
| Short high-precision rules with a probability guarantee | Ribeiro, Singh, and Guestrin, **Anchors**, AAAI 2018, searches sufficient-condition rules with high-probability precision requirements and seeks broad coverage. [Paper](https://homes.cs.washington.edu/~marcotcr/aaai18.pdf) | Deployment-distribution coverage, per-cluster guarantees, and a complete assignment system are different targets. | Calibrate many candidates, then choose an acceptable one | Angelopoulos et al., **Learn then Test** (2021 preprint), formulates predictive risk calibration as multiple hypothesis testing and supports simultaneous risk constraints. [Paper](https://arxiv.org/abs/2110.01052) | A novel theorem must exceed a direct application of independent calibration and simultaneous testing. Adaptive candidate generation, routing, and reuse of calibration observations require explicit treatment. |

These are direct overlaps, not claims that the cited methods solve the full proposed problem or dominate it empirically. This audit does not repeat the already identified TAO, Kauri, SpEx, FAUST, and Convex comparisons.

## Does joint population-and-rule discovery rescue the claim?

**Joint discovery alone does not.** Lawless et al., **Interpretable Clustering via Multi-Polytope Machines**, AAAI 2022, jointly forms clusters and polytope explanations, permits sparse integer or axis-parallel hyperplanes, and optimizes using alternating minimization and coordinate descent. This is the nearest counterexample to “we discover the population and its sparse rule together.” [Primary paper](https://ojs.aaai.org/index.php/AAAI/article/view/20693)

Independent replication alone is also established. Tibshirani and Walther's **Prediction Strength** (2005) evaluates how well independently obtained clustering structure can be predicted across data splits. Kimes et al.'s **Statistical Significance for Hierarchical Clustering** (Biometrics 2017) adds sequential cluster tests and multiplicity-aware stopping under a specified Gaussian null. These address different questions, but prevent presenting validation, stopping, or refusing unsupported splits as new concepts. [Prediction Strength](https://gwalther.su.domains/predictionstrength.pdf), [SHC](https://pmc.ncbi.nlm.nih.gov/articles/PMC5708128/)

Thus “MPC/TAO plus replication filtering” is the immediate assembly baseline. A replication score becoming part of model selection does not automatically create independent evidence: the data used to choose the rule or threshold have then become selection data.

**Residual novelty hypothesis worth testing:** develop an efficient search for a native two-way population rule whose original-feature support is provably minimal, or has a defensible approximation/optimality gap, among a precisely defined rule family satisfying declared population-separation, minimum-mass, and replication requirements. Return an uncertainty-aware set of interchangeable supports when warranted, and decline a split when evidence is inadequate. The research contribution would be the coupled search and valid post-search inference, rather than the presence of sparse rules or validation.

This is a hypothesis, not a novelty finding. It needs a specific new algorithm or theorem. For example, equivalence-aware search bounds might avoid repeatedly searching correlated alternative supports while retaining an explicit guarantee about the supports omitted. An ordinary greedy feature search followed by a binomial interval would not establish that contribution. Exhaustive enumeration on a tiny discretized problem proves correctness only within that problem, not a scalable method or population minimality.

One node is the appropriate first target. A full hierarchy adds routing, accumulating feature costs, and dependent selection before the central claim has been demonstrated. Alternative panels can be a later consequence of a solved search problem.

## Define what the guarantee would mean

There are three separate targets: agreement with a fixed reference partition, reproducibility when discovery is repeated, and evidence for population structure. A highly reproducible threshold through a single unimodal distribution can satisfy the first two without establishing a scientifically meaningful population split.

For reference fidelity, freeze a discovery-trained assignment function `C_D(x)`. Learn candidate selective rules independently of certification data. Useful quantities for each reference cluster `k` are:

- Acceptance: `P(rule(X) != abstain | C_D(X) = k)`.
- Selective error: `P(rule(X) != C_D(X) | rule(X) != abstain, C_D(X) = k)`.

Control these simultaneously over the candidates and clusters among which selection is allowed. Nonempty, nontrivial acceptance is essential. Rule precision conditional on its *predicted* cluster is a different quantity. Node-wise guarantees do not automatically yield a guarantee for an adaptively routed final tree; certify the composed policy or prove the composition result. These are design requirements derived from the target, not claims that a particular cited paper has solved it.

Actual latent-cluster coverage is harder. Hur, Nath, and Allen's April 2026 preprint **Inference for Clustering: Conformal Sets for Cluster Labels** explicitly targets unobserved population labels up to permutation. It uses stochastic labels and obtains a finite-sample marginal-coverage lower bound involving soft-label consistency and replace-one stability, with asymptotic results under conditions. It does not provide an assumption-free guarantee that any estimated partition is ground truth. [Primary manuscript, Sections 2–3](https://arxiv.org/html/2604.03488v2)

That paper's warning about estimated labels must not be misread: conditional on an independently frozen `C_D`, new pairs `(X, C_D(X))` can support valid reference-fidelity calibration. The certificate then concerns `C_D`, not latent biological or other semantic truth.

“Near-minimal” must name the feasible family and tolerance. Inclusion-minimal, smallest-cardinality, and near-optimal penalized-loss solutions are different claims. Failure to find a three-feature rule is not evidence that none exists. Finite-sample uncertainty also separates “certifiably feasible” from “truly feasible”; claiming population minimality needs assumptions or explicit unresolved bounds.

## Five hard novelty tests before a broad benchmark

1. **Reduction test.** Compare the proposed node against alternative feature selection or TreeFARMS on frozen cluster labels, Cluster-Explorer/polyhedral descriptions, and a native MPC/TAO node, using the same held-out certification. If the gain disappears under matched budgets and certification, the result is integration rather than the claimed methodological advance.
2. **Minimality test.** On small problems, enumerate the stated grammar and all feature supports to obtain an oracle. Include duplicated and correlated measurements, irrelevant variables, and multiple equally good supports. Report support cardinality, missed alternatives, optimality gap, and search cost. Do not treat coefficient sparsity or agreement with one chosen support as the whole objective.
3. **Population test.** Predeclare the structural null and the meaning of replication. Include a no-cluster unimodal distribution, an ordinary mean split, a sparse covariance/radial split, and genuinely overlapping populations. Require calibrated refusal on the null, useful recovery where a small rule exists, and candid failure where it does not. Stable arbitrary partitions must not count as discovery success.
4. **Selection test.** Repeat discovery, search, selection, and certification across independent datasets. Increase the number of candidates; include rare groups and overlapping rules. Check the claimed simultaneous error rate and acceptance, with an untouched final evaluation sample. Testing only a preselected successful rule bypasses the hardest part.
5. **Native-rule test.** Recompute every accepted assignment from the published original-feature rule alone. Count path and whole-system features, resolve conflicts, and include abstentions in coverage. Demonstrate that the proposed search improves a relevant trade-off beyond merely allowing a more expressive geometry or hiding a full-feature fallback.

If one node passes these tests and has a nontrivial search/inference result, a wider benchmark becomes justified. At present, the defensible conclusion is that the broad idea has substantial prior overlap, while certified minimal native population-rule discovery is a narrower, unverified research direction deserving a concrete feasibility test.
